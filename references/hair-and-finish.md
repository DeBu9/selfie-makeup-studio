# 05 发型、发色与整体氛围

发型在"自拍妆效图"里有双重身份：**画面元素**（影响构图与气质）和**修饰工具**（影响脸型比例）。但它也是最容易破坏身份一致性的部分——所以默认不改，只在用户明确要"换个造型"时才动。

---

## 1. 脸型 → 发型（修饰逻辑）

| 脸型 | 目标 | 适合 | 避免 |
|---|---|---|---|
| 圆脸 | 纵向拉长 | 侧分、顶部蓬松、锁骨发、长直/大波浪 | 齐刘海、贴头皮直发、耳上短发 |
| 方脸 | 柔化下颌角 | 带弧度的卷、层次剪裁、鬓角碎发遮颧骨与下颌 | 齐平一刀切到下颌、露全脸的紧扎 |
| 长脸 | 横向加宽、缩短中庭 | 空气刘海/八字刘海、横向波浪、耳侧蓬松 | 中分贴头长直、高颅顶过度 |
| 菱形脸 | 填太阳穴、弱化颧骨 | 八字刘海、微卷侧发、颧骨位置有弧度 | 全露额、耳上极短 |
| 心形脸 | 弱化额头、平衡下巴 | 轻盈层次短发、锁骨发、侧分 | 厚重齐刘海、头顶过蓬 |
| 梨形脸 | 上半加宽 | 顶部蓬松、耳上层次、侧分 | 贴头、下半厚重 |

**头骨适配**：亚洲人常见后脑扁、颅顶低。解决靠"逆向吹发根 + 后脑外翻弧度"，视觉上把头部做成饱满椭圆。生成图像时同理——若用户发型结构没变，不要偷偷改颅顶高度（会显得不像本人）。

---

## 2. 发色 → 季型

| 季型 | 推荐发色 | 避免 |
|---|---|---|
| 春 | 金棕、蜂蜜茶、浅栗 | 纯黑、冷灰 |
| 夏 | 冷棕、亚麻灰、雾感茶 | 橘棕、金铜 |
| 秋 | 红棕、栗棕、焦糖、巧克力 | 冷灰、荧光 |
| 冬 | 黑、深棕带冷调、蓝黑 | 暖金、橙棕 |

发色与妆容的关系：发色偏暖 → 眉色可偏暖棕；发色偏冷 → 眉色走灰棕。眉色永远比发色浅一度。

---

## 3. 发质与呈现

| 发质 | 视觉特征 | 生成提示词 |
|---|---|---|
| 粗硬 | 毛躁、支撑力强 | coarse hair, thick strands |
| 细软 | 易塌、贴头 | fine hair, soft volume |
| 受损 | 干枯、无光 | dry ends, matte texture（避免过度油亮） |
| 烫染 | 卷度、色差 | 保持卷度与色阶，不要"熨平" |

---

## 4. 整体氛围：让效果图"像一张照片"而不是"一张贴图"

生成层需要的环境描述（不改变人脸，只统一画面）：

| 维度 | 建议值 | 原因 |
|---|---|---|
| 光线 | 45° 侧前方柔光 / 窗光 | 能体现妆容层次，避免正面平光吃掉修容 |
| 色温 | 5000–5600K（中性偏暖） | 偏冷会让暖色妆容失真，偏暖会让冷调发灰 |
| 背景 | 纯净浅灰 / 米白 / 虚化室内 | 不与妆容争色 |
| 镜头 | 85mm 等效、半身或近景 | 人脸占比 >35%，身份保持更稳 |
| 质感 | 保留皮肤纹理与毛孔 | 去纹理 = 塑料感 = 一眼假 |
| 表情 | 与输入图一致（默认中性微收下巴） | 改表情会连带改脸 |

**氛围一致性规则**：妆容色温、发色、服装、背景四者不能互相打架。最省事的做法是——**只改妆，其他全部锁死**。

---

## 5. 默认策略（写进 skill）

```json
"hair": {
  "change": "none",          // none | color | style | both
  "styling": "keep",          // keep | tidy | restyle
  "preserve": ["hairline", "hair volume", "hair color", "parting"]
}
```

只有三种情况允许改动：
1. 用户明确要求（"顺便给我换个发型/发色"）；
2. 原图发丝遮挡面部关键区域（眉、眼、唇），影响妆容呈现 → 只做"轻微拨开"，不改结构；
3. 用户选择"造型方案"模式（输出 3 套风格 + 对应发型建议），此时发型作为**建议**输出，不直接在图上改。

理由：发型是身份识别的最强视觉线索之一（仅次于脸型），改发型带来的"不像本人"风险远高于收益。
