# 04 风格配方（参数化）

风格不是"感觉"，是一组可复现的参数。下表每一行都能直接落成 `style_recipes.json` 里的一条记录。强度统一 0–1。

> 2026 的现实：主流审美已从"遮盖改造"转向"放大原生"——白开水、雾润唇、野生毛流、云朵肌是当前基本盘；厚重截断、全包黑眼线、高饱和荧光色在日常场景已明显退潮。配方设计遵循这个趋势，但保留浓妆档位给约会/晚宴/拍照。

## 2. 六个重点配方（含关键点与避坑）

### 2.1 白开水 / 伪素颜 `water`

- **逻辑**：不是"少化妆"，是"看起来皮肤本来就这么好"。所有步骤都做，但每步收着来。
- 底妆：妆前只保湿；有色面霜或薄粉底；只遮泛红与暗沉；只定 T 区与眼下，脸颊保留微光。
- 眉：只用浅灰棕眉粉补空隙，**不勾完整轮廓**；透明眉胶梳毛流；深发也拒绝纯黑眉。
- 眼：单色哑光浅棕消肿；不画外眼线；夹翘 + 纤长睫毛膏；卧蚕阴影极淡。
- 修容：只用余粉轻扫鼻侧，下颌线可完全省略。
- 腮红唇：膏状蜜桃点拍面中（像透出来的血色）；裸粉唇泥薄涂、边缘模糊。
- **避坑**：粉底过白 → 面具；全脸定妆 → 失去呼吸感；眼影范围过高 → 显脏；深色修容 → 一秒变浓妆。

### 2.2 泰式白开水 `thai_water`

- **逻辑**：泰妆的"结构感" + 白开水的"低饱和"。是 2026 最实用的"淡而精致"路线。
- 眉：野生微弯，眉中加粗、眉尾自然下落，灰棕+浅棕混色。
- 眼：浅粉棕铺眼皮，深棕加深眼尾 + 下至（下眼睑后段），纵向消肿；棕色眼线眼尾**微扬不尖锐**；仙子毛分段贴眼尾。
- 修容：灰调双 C 画山根，下颌线大面积柔和扫开收外轮廓。
- 腮红唇：粉橘膨胀色斜扫苹果肌衔接修容；镜面奶茶裸唇中和修容冷感。
- **避坑**：浓黑粗眼线、高饱和橘红眼影、过重古铜修容、哑光深暗唇——这四项一出就不是泰式白开水了。

### 2.3 韩系水光 `korean_glass`

- 底妆是灵魂：光泽饰底乳 + 局部遮瑕，追求"刚保养完"的透亮，而非厚覆盖。
- 眉：平缓微弯，颜色浅于发色；眼线只做内眼线 + 极细平拉尾。
- 腮红用膨胀色（牛奶粉/浅紫粉）打面中，营造微醺膨润。
- 唇：水光唇釉，渐变或满涂但边缘柔和。
- **避坑**：水光≠油光。生成时必须写 `natural glow, not greasy`。

### 2.4 日系透明感 `japanese_sheer`

- 腮红是主角，且位置偏高（眼下/颧骨上方），营造"晒红"血色感，可轻带鼻梁。
- 底妆偏半雾面奶油肌，保留皮肤纹理，不追求无瑕。
- 眼影湿润感大地/珠光，睫毛根根分明；唇选杏桃/豆沙润泽型。
- **避坑**：腮红位置过低 → 显土；腮红过重 → 变"高原红"。

### 2.5 中式氛围感 `chinese_mood`

- 核心是"留白 + 对比"：干净底妆 + 浓郁唇色，中间层次克制。
- 底妆哑光雾面，眉微挑有锋，眼线细长上扬（这是中式标志），眼影以灰棕/藕粉加深眼尾。
- 唇：正红/砖红，唇线清晰，唇峰明确。
- **避坑**：全脸堆色 → 变"舞台妆"；底妆不干净 → 红唇显廉价。

### 2.6 Latte 拿铁 `latte`

- 单色系暖棕：眼、颊、唇同一咖啡色族（espresso / caramel / mocha / cinnamon）。
- 底妆水润，用**膏状**修容（bronzer）而非粉状，融进皮肤。
- 腮红弃粉色，用暖棕/陶土；睫毛膏用棕色不用黑色。
- **避坑**：冷皮做 latte 会显脏——这是暖季型专属。

## 3. 风格推荐逻辑（auto 模式）

先算"适配分"，再按用户意图加权。硬否决项优先级最高。

**硬否决（直接排除）**
- `density = light_feature` 且 `feature_size = small` → 排除 `western_sculpt` `abg` `evening_glam`
- `face_shape = round` 且 `bone_vs_flesh < 0.4` → 排除 `western_sculpt` `abg`（会显凶）
- `undertone = warm/olive` → 排除 `y2k_ice`；`undertone = cool` → 排除 `latte` `thai_glam` 强暖版
- `skin.concerns` 含 `active_acne` → 排除 `dewy` 系妆效（反光放大瑕疵）
- `midface_ratio > 1.08`（中庭偏长）→ `chinese_mood` / `evening_glam` 需降强度 0.15，且必须启用腮红横打

**加分项**
- 淡颜 + 冷皮 + 通勤 → `water` `korean_glass` `clean_girl`
- 淡颜 + 暖皮 + 春夏 → `thai_water` `strawberry`
- 浓颜 + 骨相 + 拍照 → `chinese_mood` `thai_glam`
- 高对比（黑发白皮）+ 派对 → `y2k_ice` `evening_glam`
- 暖皮 + 秋冬 → `latte` `thai_glam`
- `visual_age = youthful` 且 `face_shape = round` → `japanese_sheer` `strawberry`

**输出**：Top 3 候选 + 每条的"为什么适合你"一句话（用 analysis 里的具体数值，不要泛泛而谈）。这句话本身就是产品价值。

## 4. 场景调节（同一风格的强度缩放）

| 场景 | 强度系数 | 额外调整 |
|---|---|---|
| 日常/通勤 | ×0.8 | 降低眼线长度与唇饱和 |
| 约会 | ×1.0 | 腮红 +0.05，唇改水光 |
| 拍照/上镜 | ×1.1 | 修容 +0.1（镜头吃妆），妆效切 `cloud` |
| 晚宴/活动 | ×1.3 | 允许高对比唇、加睫毛 |
| 婚礼/正式 | ×1.2 | 妆效转 `soft_matte`，避免闪光灯反光 |

强度缩放后仍需过一遍上限：淡颜 0.45 / 中性 0.65 / 浓颜 0.85。
