# 03 手法与执行链

知识库里最容易被忽略、但对生成质量影响最大的一层：**同一个色，画在不同位置、用不同边缘处理，结果完全不同**。生成模型对"位置"和"边缘硬度"的响应，比对着色的响应更明显。

---

## 1. 标准顺序（顺序错 = 妆面脏）

```
护肤（精简） → 防晒（等成膜） → 妆前（局部） → 色彩校正 → 粉底 → 遮瑕 → 眉毛
→ 眼部打底 → 眼影 → 眼线 → 睫毛 → 修容 → 高光 → 腮红 → 唇 → 定妆
```

三个顺序铁律：
1. **防晒必须成膜再上底妆**（约 3–5 分钟），否则搓泥。
2. **每层之间留 30–90 秒**让配方成膜，否则下层被上层"拖走"。
3. **修容在腮红前**：先造阴影再上颜色，颜色才不会压住轮廓；化妆师做法反过来也行，但**修容必须最后用余粉轻扫**，不能重手。

---

## 2. 面部坐标词表（提示词专用）

生成模型对解剖学词汇的响应远好于"脸颊""眼睛下面"这类模糊描述。统一用下表：

| 区域 | 坐标描述 | 用途 |
|---|---|---|
| 山根 | 两眼之间、鼻梁最上端 | 鼻影起点（**不连眉头**） |
| 眼窝三角 | 内眼角上方到眉头的凹陷三角 | 消肿打底、深邃感 |
| 眼尾三角 | 外眼角向太阳穴方向的三角区 | 加深拉长眼型 |
| 双眼皮褶皱内 | 睁眼时褶皱以下区域 | 主色范围上限 |
| 卧蚕 | 下睫毛根下方 2–3mm 的条状隆起 | 阴影 + 提亮 |
| 眼头 | 内眼角 | 珠光提亮（少量） |
| 颧骨最高点 | 外眼角垂线与鼻翼水平线交点附近 | 珠光高光落点 |
| 苹果肌 | 颧骨最高点偏内、笑起来鼓起处 | 腮红主区 |
| 面中 | 眼下到鼻翼的中央区 | 膨胀色腮红、哑光提亮 |
| 太阳穴 | 眉尾延长线与发际线之间的凹陷 | 凹陷需提亮，**修容要避开** |
| 下颌线 | 耳下到下巴下缘的轮廓线 | 轮廓修容，从耳下向嘴角 |
| 下颌角 | 耳下方拐角 | 方脸柔化时从角上方起笔画弧线 |
| 发际线 | 额头最上缘 | 额头宽时修容 |
| 鼻基底 | 鼻翼两侧与面颊交界的凹陷 | 哑光提亮，改善"面中塌" |
| 泪沟 | 内眼角斜向下的凹陷 | 只用哑光提亮 |
| 法令纹 | 鼻翼到嘴角的沟 | 只用哑光提亮 |
| 唇峰 | 上唇中央的 V 形隆起 | 珠光/唇线重塑 |
| T 区 / U 区 / C 区 | 额头+鼻 / 两颊+下巴 / 眼角下到颧骨 | 分区控油与定妆 |

## 3. 底妆

| 步骤 | 手法 | 量 | 关键 |
|---|---|---|---|
| 妆前 | 局部使用（毛孔区/干区），不全区厚涂 | 黄豆大小 | 保湿与控油分区，T 区控油、U 区保湿 |
| 色彩校正 | 点拍，只覆盖问题区 | 米粒大小 | 绿遮红、橘遮青紫黑眼圈、紫去黄 |
| 粉底 | 面中点涂 → 向外拍开；刷子铺开、海绵收尾 | 一层薄，可叠 2 层 | **由内向外**，边缘留渐变；不要一次厚涂 |
| 抛光（可选） | 用干净海绵以"弹"的方式按压 | 无新增产品 | 提升干净度，适合上镜 |
| 遮瑕 | 点戳，不拖拽 | 极少 | 眼下用最细的粉，越靠下越薄 |
| 定妆 | 散粉压 T 区 + 眼下；脸颊用定妆喷雾 | 薄 | 干皮只喷雾；油皮散粉全脸但颊部轻扫 |

**妆效与肤质映射**：干皮 → `dewy/satin` + 滋润型；油皮 → `soft_matte` + 控油妆前 + 散粉；混合 → 分区；敏感 → 少层数、少摩擦。

## 4. 眉

1. 定眉底线（决定眉高与走势）
2. 定眉峰（圆脸/方脸略高，长脸偏低）
3. 连眉尾（长度 ≈ 鼻翼到外眼角的延长线）
4. 顺毛流一根根补空隙（**不勾外框**）
5. 眉头最淡（"轻-重-轻-重"节奏），用螺旋刷向前晕
6. 染眉膏统一色调，透明眉胶梳毛流

避坑：整条描边 → 蜡笔小新；眉头过重 → 显凶；颜色比发色深 → 显硬。

---

## 5. 眼妆（分四层，逐层加范围）

| 层 | 范围 | 颜色 | 目的 |
|---|---|---|---|
| L1 打底 | 整个眼窝（睁眼可见区） | 最浅哑光 | 均匀肤色、消肿 |
| L2 主色 | 双眼皮褶皱内 / 单眼皮睁眼可见边缘 | 中间色 | 建立色调 |
| L3 加深 | 眼尾三角 + 睫毛根部 | 最深色 | 深邃、拉长 |
| L4 提亮 | 眼头、眼球中央、卧蚕 | 珠光/细闪 | 立体、湿润感 |

**眼线三种走向 = 三种气质**：平拉（自然）、微上扬（提神/猫眼）、下垂（无辜/狗眼）。内眼线只填睫毛根空隙，不外扩；外眼线从眼尾 1/3 起笔最安全。
**睫毛**：三段夹（根/中/梢）→ 打底 → Z 字刷根部再向上提拉 → 用纸巾蹭掉多余膏体防"苍蝇腿"。
**下眼影**：范围不超过下眼睑 1/2，越往外越淡，否则显脏。

---

## 6. 修容 / 高光

**修容三笔法（外轮廓）**：发际线 → 颧骨外下（从后向前画三角，最宽处最深）→ 下颌线（耳下向嘴角）。方脸把下颌线改成**弧线**，从下颌角上方起笔。
**鼻影**：山根两侧起笔（眼窝三角），向下晕到鼻头；鼻头两侧"小括号"接鼻小柱成 V，括号不闭合；上缘不超过唇峰延长线。
**哑光高光**：泪沟、法令纹、眉心、鼻基底、下巴尖、眼头 3mm 内。
**珠光高光**：鼻尖、鼻梁中段（断开，不拉通条）、颧骨最高点、眉骨下、唇峰。

**强度换算**（写进规则表，避免"下手重"）：
- `0.1–0.2` 几乎不可见，只修光影
- `0.25–0.35` 日常（白开水/通勤上限）
- `0.4–0.55` 有明确妆感（韩系/日系/中式）
- `0.6–0.8` 浓妆（泰式/欧美/ABG/晚宴）

---

## 7. 腮红

顺序：膏状打底（融肤）→ 粉状薄盖（定色）→ 用上过粉底的海绵轻拍边缘融合。
手法：从落点向外轻扫，**边缘必须晕到无边界**；面中留白，不要糊满。
位置决策见 `02` 第 4 节。硬禁忌：低于鼻尖、与修容重叠、两边不对称。

---

## 8. 唇

1. 润唇打底（去死皮，避免卡纹）
2. 深唇先薄薄中和（遮瑕或偏灰棕膏状修容，轻拍，不要抹没）
3. 唇线笔勾形（范围控制在唇线内外 0.5mm）
4. 用棉签/小刷把唇线向内晕成"影子"
5. 色料从唇中央点涂，向外晕
6. 需要体积感时，唇峰 + 下唇中央点高光

---

## 9. 翻车 → 原因 → 修正（质检用）

| 现象 | 根因 | 修正 |
|---|---|---|
| 面具脸 / 脸脖分层 | 粉底过白、色阶错 | 降到颈部色阶 +0.5 以内；颈部带下过渡 |
| 搓泥 | 护肤未成膜、层数过多 | 减少层数，每层间隔 30–90s |
| 卡粉起皮 | 干皮未保湿 / 粉太厚 | 加强保湿、减少粉量、改用喷雾定妆 |
| 妆面脏 | 修容暖棕、腮红与修容重叠、晕染不到位 | 换冷灰棕、留白、边缘晕开 |
| 显凶 | 眉头重、眼线上扬、修容过重 | 眉头减淡、眼线平拉、修容降 30% |
| 显老 | 中庭长 + 眼尾下垂 + 哑光厚粉 | 腮红横打截断中庭、眼尾上提、改缎面妆效 |
| 眼肿 | 珠光/高饱和红橘、范围过高 | 换哑光大地色、范围压到褶皱内 |
| 眼睛变小 | 全包粗眼线、睫毛结块 | 只填内眼线、睫毛薄刷 |
| 唇薄/无气色 | 低饱和裸色 + 深唇未打底 | 提饱和、先中和唇色 |
| 塑料感（AI 特有） | 过度磨皮、缺纹理、珠光过量 | 加 skin texture / visible pores，减 shimmer |

---

## 10. 用量与工具（影响真实感的关键细节）

- 粉底：全脸约 1 泵；遮瑕：每处米粒大；散粉：按压取粉后**弹掉九成**再用。
- 刷具分工：大蓬松刷（晕染）、斜角紧实刷（精准修容）、扁平小刷（眼头/下眼影）、螺旋刷（眉）、海绵（收尾与融合）。
- 边缘处理优先级：**任何颜色的边缘都比颜色本身重要**。生成提示词里要显式写 `blended edges, no harsh lines`。
