# 方案卡写作规范

方案卡是这个 skill 和"AI 试妆滤镜"的分水岭。滤镜只给一张图，我们给的是**能照着化出来的操作说明**。
判断标准只有一条：**一个从没化过妆的人，能不能靠这张卡在 15 分钟内做出七八成效果。**

`scripts/plan_makeup.py` 已经按本规范生成了完整卡片（`card_*.md` / `card_*.html`），
通常不需要重写。需要的时候按下面的规则改，别把结构改散。

---

## 一、卡片的十一个部分

1. **标题**：风格名 + 脸型/量感/肤色标签（一眼知道自己为什么被推这套）
2. **原图 / 妆后对比**：左右并排，标"原始照片"与"妆后效果 + 强度"。
   由 `scripts/attach_result.py` 在出图后注入（base64 内嵌，卡片单文件自包含）。
   没有这一步，用户拿到的只是文字方案，看不到效果——这是最容易漏的一环。
3. **手法动效**：四张**局部放大**的示意图（腮红方向 / 鼻影起止 / 眼线起笔 / 眼影范围）。
   由 `scripts/attach_motion.py` 按 spec 参数渲染：浅色宽带=范围、深色线=笔迹、
   人字箭头=方向、小刷头=正在运笔。笔迹用 `stroke-dashoffset` 逐笔长出，刷头用
   `animateMotion` 沿同一路径走并自动转向，循环 3.2 秒。
   导出长图/PDF 时会注入 CSS 关掉动画、补全笔迹——**静图必须看起来是画完的**。
   图不是装饰，是回答"手往哪走"；整张脸画不下手部动作，所以放大到局部。
4. **四项指标**：妆容强度（0–1）、妆效、遮瑕度、预计耗时
5. **为什么这套适合你**：3–6 条"特征 → 动作"的因果句，每条都要有依据
6. **用到的色**：按部位给色系 + 中文描述 + 参考色块（不给品牌色号）
7. **上妆顺序**：14 步左右，从护肤到收尾
8. **三个最容易翻车的地方**：只给三条，多了记不住
9. **边界说明**：预览非医美、AI 生成标识
10. **复现参数**：style id / intensity / finish（方便下次微调）
11. **可打印**：A4 打印不截断，微信里截图能看清

## 二、每一步必须有六个要素

这是整张卡的核心。缺一项，新手就会卡住。

| 要素 | 要回答的问题 | 反例 | 正例 |
|---|---|---|---|
| 工具 | 用什么 | "用刷子" | "斜角紧实刷 + 冷灰棕修容粉（不要暖棕、不要带闪）" |
| 用量 | 取多少 | "适量" | "刷子蘸粉后在手上抖两下；遮瑕每处米粒大小" |
| 位置 | 画在哪 | "画在脸颊" | "从颧骨下方斜向上，横过鼻梁上缘，不低于鼻尖" |
| 手法 | 怎么做 | "晕开" | "由内向外拍开，边缘越往外越薄，最后用干净海绵按压" |
| 停手标准 | 到什么程度算好 | "自然一点" | "脸和脖子没有明显色差，毛孔还看得见" |
| 常见错 | 最容易错在哪 | "小心点" | "一次倒太多、反复叠 → 卡粉、假面" |

### 停手标准怎么写

必须能被**肉眼验证**，不能靠感觉：

- ✅「睁眼时睫毛根没有留白」「笑起来眼下不卡纹」「正面看是阴影不是颜色」「手指按上去不留指纹」
- ❌「看起来自然」「不要太浓」「适当即可」

### 位置怎么写

用解剖坐标 + 可触摸的参照物，两者一起给：

- 「眉峰：黑眼球外缘向上延伸的位置」
- 「卧蚕：下睫毛根下方 2–3mm 的条状隆起」
- 「腮红：从苹果肌下缘斜向上扫到太阳穴，范围不超过两指宽」
- 「眼影：双眼皮褶皱内，睁眼刚好露出 1–2mm」

参照物清单：米粒（遮瑕）、黄豆（粉底/保湿）、硬币（防晒/腮红范围）、
食指指甲盖（珠光范围）、两指宽（腮红长度）、一支笔的宽度（眼线长度）。

## 三、语言规范

1. **动词开头，一句话一个动作。** 「点涂」比「可以用点涂的方式」好。
2. **给顺序的理由。** 「先修容再腮红，是因为颜色会压住轮廓」——知道为什么，才不会自己改顺序。
3. **不写品牌硬广。** 只写品类与色系（"丝绒雾面唇釉，奶茶色系"），不写"XX 牌 999"。
4. **不写绝对化承诺。** 不写"一定显白""立刻变好看"。写"会……"的机制描述。
5. **不写医美建议。** 不评价"你该做热玛吉/瘦脸针"。
6. **称呼用"你"，不用"宝宝/姐妹"。** 保持专业但不冷漠。
7. **长度控制。** 每个步骤 6 行以内；整卡控制在 2 屏到 3 屏。太长没人看完。

---

## 四、三个让新手真正做对的技巧

1. **给"错的样子"而不只是"对的样子"。** 「如果眼影边缘出现一条明显的分界线，说明没晕开」比「要晕开」有效。
2. **把最难的一步拆开。** 眉毛是新手最大的坎，就拆成 ①眉底线 ②眉峰 ③眉尾 ④补空隙 ⑤眉头最淡 五小步。
3. **在卡里放一个"只做三件事"的版本。** 时间不够时，告诉用户哪三步做了就有 70% 效果
   （通常是：底妆匀 + 眉毛有形 + 唇有血色）。

## 五、聊天里怎么回复

卡片是完整版，聊天窗口不要复制一遍。回复结构：

```
三套方案的差别（一句话一套）
推荐哪套 + 一句理由
最容易做错的两步（各一行）
卡片文件位置
```

用户选了之后再给对应卡片，不要一开始就塞三个完整方案进对话。

## 六、常见修改请求

| 用户说 | 怎么改 |
|---|---|
| 太长了 | 保留底妆/眉/唇三步 + 其余合并成"其他部位快速版"，卡片压到 1 屏 |
| 太浓了 | 强度 ×0.7 重新出图，卡片里把"加深"那层删掉，只留打底 + 主色 |
| 我手残 | 每步加一句"如果做不好，可以跳过，代价是……" |
| 想要更日常 | 换 `water` / `smart_office` 配方重跑，不要手工改参数 |
| 想加眼线/假睫毛 | 提高强度到 0.45 以上重跑，用 `--styles` 指定风格，别在卡里硬加步骤 |
