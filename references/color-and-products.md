# 02 色彩体系与产品语言

这一层解决两件事：**她是什么色**（输入），以及**该给她什么色**（输出）。所有色名都是"色系族 + 明度/饱和度"，不绑定品牌色号——品牌色号会过时，色系不会。

---

## 1. 肤色：用可计算的方式判定

### 1.1 深度（Depth）

用皮肤科通用指标 **ITA°**（Individual Typology Angle），在 CIELAB 空间算：

```
ITA° = arctan((L* − 50) / b*) × 180 / π
```

| ITA° | 分型 | depth 值 | 常见描述 |
|---|---|---|---|
| > 55 | very light | 1–2 | 冷白/暖白 |
| 41 – 55 | light | 3–4 | 自然偏白 |
| 28 – 41 | intermediate | 5–6 | 自然肤色 |
| 10 – 28 | tan | 7 | 健康小麦 |
| −30 – 10 | brown | 8–9 | 深肤色 |
| < −30 | dark | 10 | 深黑 |

采样位置：额头中央 + 颈部侧面（**不要用脸颊**，泛红会误判冷暖）。

### 1.2 冷暖（Undertone）

- 用 `b* / a*` 比值：`b*`（黄）显著高于 `a*`（红）→ warm；`a*` 高 → cool；接近 → neutral。
- **橄榄皮（olive）特判**：`b*` 中等偏高但 `hue` 偏绿灰、整体饱和度低。表现是"金色粉底太橘、粉色粉底发灰"。这是东亚高频类型，必须单独一档，否则配色全错。
- 图像上辅助判据：手腕血管色（蓝紫=cool、绿=warm）、金银首饰对比、白纸对比——用于解释给用户，不作为唯一算法。

### 1.3 对比度（Contrast）

发色明度与肤色明度的差值，加上瞳色明度。高对比（黑发白皮）能承载强烈唇色与清晰线条；低对比（浅发浅皮）适合低饱和、模糊边缘。

### 1.4 十二季型

| 季型 | 冷暖 | 明度 | 饱和 | 典型 |
|---|---|---|---|---|
| Light Spring 浅春 | 暖 | 高 | 中高 | 明亮、金调、清透 |
| True Spring 正春 | 暖 | 中高 | 高 | 珊瑚、蜜桃、草绿 |
| Bright Spring 净春 | 暖偏中性 | 中高 | 很高 | 高饱和暖色，对比强 |
| Light Summer 浅夏 | 冷 | 高 | 低 | 粉蓝、淡紫、玫瑰 |
| True Summer 正夏 | 冷 | 中 | 低 | 灰粉、雾蓝、冷棕 |
| Soft Summer 柔夏 | 冷偏中性 | 中 | 低 | 灰调玫瑰、藕粉、鼠尾草 |
| Soft Autumn 柔秋 | 暖偏中性 | 中 | 低 | 灰驼、奶茶、干枯玫瑰 |
| True Autumn 正秋 | 暖 | 中低 | 中 | 砖红、橄榄、焦糖 |
| Deep Autumn 深秋 | 暖 | 低 | 中高 | 咖啡、赤茶、深砖红 |
| Deep Winter 深冬 | 冷 | 低 | 高 | 酒红、墨绿、深紫 |
| True Winter 正冬 | 冷 | 中低 | 高 | 正红、宝蓝、纯黑 |
| Bright Winter 净冬 | 冷偏中性 | 中 | 很高 | 荧光粉、冰蓝、纯白对比 |

> 边界型（flow type）很常见：落在两季之间时，取**中间饱和度**，避开两端极端色。这比硬塞进某一季更实用。

## 2. 底妆：质地 + 色阶 + 遮瑕

### 2.1 妆效（finish）——比色号更影响"像不像她"

| finish | 观感 | 适合 | 生成关键词 |
|---|---|---|---|
| `dewy` 水光 | 湿润反光 | 干皮、淡颜、年轻 | dewy skin, glass-skin glow, luminous |
| `satin` 缎面 | 微光泽、真实 | 通用，最安全 | satin finish, natural skin texture |
| `soft_matte` 柔雾 | 磨皮但透气 | 油皮、上镜、通勤 | soft-matte, blurred, velvet |
| `cloud` 云朵肌 | 柔焦扩散 | 2026 主流，拍照极佳 | soft-focus, airbrushed, diffused |
| `matte` 全哑光 | 无油光、强轮廓 | 欧美骨相、舞台 | matte, shine-free |

**关键**：`dewy` 在生成模型里极易变成"油光/塑料感"，需要同时写 `natural skin texture, visible pores, no plastic sheen`。

### 2.2 色阶

- 匹配位置：**下颌后方到颈部侧面**（不受两颊泛红与下巴色素沉淀影响），同时参考锁骨/胸口。
- 规则：`depth` 以颈部为准，允许比面部亮 0.5 阶做提亮，**绝不超过 1 阶**。
- undertone 标记：`W/G/Y`=暖，`C/P/R`=冷，`N`=中性，`O`=橄榄。
- 深浅优先级 **高于** 冷暖：粉底太白造成的"面具脸"比 undertone 偏差更难救。

### 2.3 遮瑕与校正

| 问题 | 校正色 | 说明 |
|---|---|---|
| 泛红/痘印 | 绿 | 薄涂，只覆盖红区 |
| 黑眼圈（青紫） | 蜜桃/橘 | 深肤色用偏橘，浅肤色用蜜桃 |
| 暗黄 | 紫/蓝（极薄） | 过量会发灰 |
| 暗沉/泪沟/法令纹 | 哑光米白提亮 | 这是"提亮"不是"遮瑕" |

## 3. 眼影：质地决定成败，色系决定气质

| 质地 | 作用 | 风险 |
|---|---|---|
| 哑光 matte | 消肿、造轮廓 | 无 |
| 缎光 satin | 提亮但不膨胀 | 少量 |
| 珠光 shimmer | 点光、增加湿润感 | 肿眼泡慎用 |
| 亮片 glitter | 舞台/派对 | 日常显廉价 |
| 膏状 cream | 融肤、氛围感 | 需要快速晕开 |

**色系族**（按使用频率排序）：

| 色系 | 组成 | 适合 |
|---|---|---|
| 大地色 earth | 米、浅咖、中棕、深棕 | 所有肤色，新手安全区 |
| 粉棕 pink_brown | 灰粉、藕粉、豆沙棕 | 冷皮、淡颜、韩系/日系 |
| 杏桃 apricot | 杏、蜜桃、浅橘 | 暖皮、春夏、元气 |
| 灰棕 taupe | 灰、冷棕、烟灰 | 冷皮、清冷/高智妆 |
| 橄榄 olive | 橄榄绿、卡其 | 秋季型、latte/复古 |
| 烟熏 smoke | 炭黑、深灰、深棕 | 晚宴、欧美 |
| 彩色 color | 冰蓝、紫、玫红 | 派对、Y2K |

**配色硬规则**：眼影饱和度 ≤ 唇色饱和度；全脸主色 ≤ 2；眼影若带冷调，腮红与唇必须同冷调。

## 4. 腮红：三种功能，位置比颜色更重要

| 类型 | 色系 | 作用 | 位置 |
|---|---|---|---|
| 膨胀色 | 牛奶粉、浅紫粉、浅蜜桃 | 让面中"鼓起来"、显幼 | 面中（瞳孔下方偏内），眼下三角 |
| 收缩色 | 裸棕、玫瑰棕、豆沙 | 收轮廓、衔接修容 | 颧骨外下方，斜向 |
| 氛围色 | 苹果红、晒伤红、珊瑚 | 造情绪（微醺/日晒） | 鼻梁横带 + 两颊高位、耳际 |

**位置即气质**：
- 高位（眼下/颧骨上方）→ 元气、日系、减龄
- 斜向上（苹果肌→太阳穴）→ 提拉、通勤
- 面中横打并带过鼻梁 → 缩短中庭（长脸/长中庭必用）
- 低位（低于鼻尖）→ **禁忌**，显下垂显土

**留白规则**：腮红区与修容区之间要留白，否则显脏。腮红边缘必须晕到"看不出边界"。

## 5. 修容与高光：两种高光不能混

| 产品 | 色 | 用途 | 位置 |
|---|---|---|---|
| 修容（鼻影/轮廓） | **冷调灰棕** | 造骨骼阴影 | 山根两侧、鼻头 V、颧骨外下、下颌线、发际线 |
| 哑光高光 | 米白/象牙 | 填平凹陷、提干净度 | 泪沟、法令纹、眉心、鼻基底、下巴尖 |
| 珠光高光 | 香槟/冰白细闪 | 造骨点反光 | 鼻尖、鼻梁中段、颧骨最高点、眉骨下、唇峰 |

> **最常见错误**：用珠光高光去填泪沟和法令纹——反光会把凹陷放大。凹陷只能用哑光。

暖棕修容在亚洲肤色上几乎必然显脏（发红、像没洗干净），所以默认 `tone = cool_gray_brown`，只有明确做"健康小麦/ABG"风格时才切暖棕。

## 6. 唇：色系 × 质地 × 形状

### 6.1 色系族（18 族，覆盖市面 90% 命名）

| 族 | 代表名 | 冷暖 | 适配 |
|---|---|---|---|
| 裸粉 nude_pink | 裸粉、杏仁奶咖 | 中性 | 淡颜、伪素颜、深唇需打底 |
| 奶茶 milk_tea | 奶茶、肉桂奶、浅裸豆沙 | 暖偏中性 | 通勤、黄皮安全 |
| 豆沙 rosewood | 豆沙、干枯玫瑰 | 中性偏冷 | 万能色，第一支口红 |
| 珊瑚 coral | 珊瑚、西柚、蜜桃 | 暖 | 春夏、元气、暖皮 |
| 番茄 tomato | 番茄红、枫叶红 | 暖 | 黄皮显白首选 |
| 砖红 brick | 砖红、赤茶、红棕 | 暖 | 秋冬、氛围感、成熟 |
| 南瓜 pumpkin | 南瓜、土橘 | 暖 | 深秋型、小麦肌 |
| 正红 true_red | 正红、中国红 | 中性偏冷 | 气场、晚宴、高对比 |
| 蓝调红 blue_red | 冷调正红、ruby | 冷 | 冷白皮、显牙白 |
| 玫红 fuchsia | 玫红、火龙果 | 冷 | 冷皮、白皮；暖皮慎用 |
| 梅子 plum | 梅子、紫调豆沙 | 冷 | 冷皮、秋冬 |
| 浆果 berry | 浆果、树莓 | 冷 | 深冬型、浓颜 |
| 酒红 wine | 酒红、勃艮第 | 冷 | 晚宴、深肤色 |
| 巧克力 chocolate | 巧克力奶棕、可可 | 暖 | 深肤色、latte 妆 |
| 土橘 terracotta | 陶土、赤陶 | 暖 | 秋季型 |
| 荧光粉 neon_pink | 芭比粉、亮粉 | 冷 | 极少人适配，默认禁用 |
| 亮橘 bright_orange | 亮橘、荧光橘 | 暖 | 显牙黄，默认禁用 |
| 透明 gloss | 透明唇蜜、唇油 | — | 叠涂、增加体积感 |

**唇色适配公式**：
- 暖皮 → 番茄 / 砖红 / 枫叶 / 红棕 / 奶茶 / 珊瑚
- 冷皮 → 玫红 / 蓝调红 / 梅子 / 浆果 / 冷豆沙
- 中性 → 豆沙 / 正红 / 奶茶 / 珊瑚（范围最宽）
- 橄榄皮 → 低饱和莓果、柔陶土、灰紫（避开纯橘与纯粉）
- 深肤色 → 高饱和正红、酒红、浆果（浅色会显苍白）

### 6.2 质地

| 质地 | 体积感 | 适合 |
|---|---|---|
| 雾面哑光 matte | 收缩 | 浓颜、正式、上镜 |
| 雾润/柔雾 soft_matte | 中性（2026 主流） | 全场景，不拔干不黏 |
| 水光/镜面 glossy | 放大 | 淡颜、年轻、日常 |
| 唇泥 velvet | 强柔焦 | 模糊唇线、氛围感 |
| 唇油 oil | 最通透 | 叠涂、裸妆 |

### 6.3 形状

`blurred_edge`（边缘模糊，最百搭）/ `defined`（清晰唇线，显精致）/ `gradient`（渐变咬唇，显幼）/ `overlined`（外扩，增厚）/ `inner`（内收，缩小）。

## 7. 高光/珠光的"安全区"

毛孔明显、干纹明显、痘坑区域**禁用珠光**。珠光只能放在：鼻尖、鼻梁中段、颧骨最高点外侧、眉骨下、唇峰、眼头、卧蚕内 2/3。这个白名单要写进规则表，避免生成模型把整张脸打亮。
