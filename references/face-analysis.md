# 01 面部分析体系（可计算版）

分析层的目的不是"描述长相"，而是输出**能被规则表消费的枚举值 + 程度值**。所有条目都给了可量化的判据，方便从 68/468 点人脸关键点直接算。

---

## 1. 脸型：先算比例，再定名字

判据用四个量（`W_t` 额宽、`W_z` 颧宽、`W_j` 下颌角宽、`L` 发际线到颏底）：

| 指标 | 计算 | 用途 |
|---|---|---|
| 长宽比 `R = L / W_z` | — | 圆脸 <1.25，鹅蛋 1.3–1.45，长脸 >1.55 |
| 上宽比 `W_t / W_z` | — | <0.85 心形/菱形倾向，≈1 方/圆 |
| 下宽比 `W_j / W_z` | — | >0.9 方脸，<0.7 心形 |
| 下颌角 `θ` | 下颌线夹角 | >130° 柔和，110–125° 骨感 |

| 脸型 | 特征 | 视觉问题 | 修饰主线 |
|---|---|---|---|
| 鹅蛋 oval | 比例均衡，下颌圆润 | 几乎无 | 保持轮廓，重点做"精致度"而非"修正" |
| 圆脸 round | 长宽接近，软组织多 | 显幼态但缺立体 | 纵向拉长：高光打面中竖条，腮红斜向上，修容收下颌角与面侧，避免横向腮红与齐刘海 |
| 方脸 square | 下颌角明显，下宽大 | 硬朗 | 柔化棱角：下颌角上缘起笔走**弧线**而非直线，腮红偏圆打，眉形略带弧度 |
| 长脸 long | 纵向过长 | 显成熟、显疲惫 | 横向拉宽：腮红横打、修容压额顶与下颌、平直略粗眉、刘海缩短上庭 |
| 菱形 diamond | 颧骨最宽，额头/下颌窄 | 颧骨突兀、太阳穴凹 | 弱化颧骨：颧骨最高点下方打阴影、太阳穴与面中提亮、腮红打在颧骨内侧 |
| 心形/倒三角 heart | 上宽下尖 | 额头宽、下巴尖 | 收额头：发际线两侧修容，腮红位置下移，下颌线提亮 |
| 梨形/三角 triangle | 下宽上窄 | 显得下半脸重 | 提亮上庭与面中，下颌角重修容，头顶做蓬松 |
| 方圆 soft square | 方中带肉 | 介于两者 | 按方脸手法但降低强度 30%，保留肉感 |

> 硬规则：**修容只做"视觉收缩"，不做"结构改造"**。强度上限 0.35（浓妆风格可到 0.5），超过就会出现"两条黑杠"。

## 2. 三庭五眼：比例的量化与修正

**三庭**（纵向三等分）：上庭 发际线→眉心；中庭 眉心→鼻底；下庭 鼻底→颏底。
标准为 1:1:1，实际允许 ±8%。输出 `upper:mid:lower` 三元组，判定哪一庭偏长/偏短。

| 偏差 | 视觉后果 | 修正动作 |
|---|---|---|
| 上庭偏长 | 发际线高、显成熟 | 刘海/碎发遮挡；发际线修容；眉位略上移 |
| 上庭偏短 | 额头局促 | 露出额头、头顶蓬松、眉位下移 |
| 中庭偏长 | 显成熟、显智性、易显疲惫 | 腮红**横打并带过鼻梁**（截断中庭）；卧蚕下移；眉形压低；避免鼻影拉太长 |
| 中庭偏短 | 幼态、显甜 | 拉长眉眼线条、眉尾延长、腮红斜向上、鼻影可略拉长 |
| 下庭偏长 | 下巴长、显硬 | 下唇略画厚、下巴阴影上移、腮红下移 |
| 下庭偏短 | 下巴后缩感 | 下巴尖高光、下唇中间提亮、避免下巴重阴影 |

**五眼**（横向）：脸宽 ≈ 5 个眼长。核心是 `眼距 / 眼长`：

| 眼距 | 气质 | 修正 |
|---|---|---|
| 宽（>1.15 眼长） | 松弛、天真、幼态 | 内眼角提亮收敛、内眼线延长、眉头内移、鼻影山根加宽 |
| 标准（0.95–1.15） | 均衡 | 不修正 |
| 近（<0.95） | 精致、锐利、有攻击性 | 眼尾向外晕染、外眼角提亮、眉头外移、鼻影收窄 |

其他横向指标：`鼻宽/嘴宽`（>0.75 鼻翼偏宽）、`颧宽/脸宽`（>0.92 颧弓外扩）、`下颌角间距/脸宽`。

## 3. 眼型：决定 80% 的妆容成败

| 眼型 | 识别 | 妆容目标 | 关键手法 | 避坑 |
|---|---|---|---|---|
| 单眼皮 mono | 无褶皱，眼皮平 | 制造纵向轮廓 | 眼影纵向窄、横向拉长；睁眼能看到边缘即可；眼线只画后半段；眉眼距远则眉下移造"眉压眼" | 眼影范围过宽→显脏显肿 |
| 内双 inner_double | 有褶但被上睑覆盖 | 提神、放大 | 浅色打底提亮眼皮；眼线**填睫毛根**不要加粗；重点做睫毛与卧蚕 | 粗眼线会被吃掉还显脏 |
| 双眼皮 double | 褶皱明显 | 发挥空间大 | 晕染到褶皱上方一点为止；可做截断、可加深眼尾 | 晕染过高显怪异 |
| 肿眼泡 puffy | 上睑脂肪厚 | 消肿 | 只用**哑光大地色**单色渐层；珠光只点在眼球正上方一点；加深眼尾三角 | 珠光/亮片/高饱和红橘→更肿 |
| 上挑眼/凤眼 upturned | 外眼角高于内眼角 | 柔和化 | 眼影重心前移、眼尾向下晕；眼线平拉或微垂；下眼尾可带一点眼线 | 上扬眼线→更凶 |
| 下垂眼 downturned | 外眼角低于内眼角 | 提神 | 眼尾向上晕染、眼线前细后粗并在眼尾前微微上扬；眉形偏平直 | 眼尾重色→更丧 |
| 细长眼 elongated | 眼裂长、高度小 | 放大圆度 | 晕染高度提到眉眼中间；眼球中央提亮；上下睫毛都做 | 只在眼尾加深→更长更细 |
| 圆眼 round | 眼裂高、显幼 | 拉长 | 眼尾横向延长、眼线平拉、下眼睑外侧加深 | 上下都加粗→像惊讶脸 |
| 深眼窝 deep_set | 眼窝凹陷、眉骨高 | 提亮 | 米色/暖金属色铺满眼睑，眉骨下提亮 | 深色大面积→更凹更显老 |

**眉眼距**：近（<1.2 眉高）显凌厉，远显柔和。远距可通过眉下移 + 眼影上缘抬高来缩短。

**卧蚕**是东亚妆容的高杠杆点：阴影落在瞳孔正下方 2–3mm，向两侧用余粉延伸；提亮只做内 2/3 段；肿眼泡用哑光，其他可用细闪。卧蚕能让眼位下移，从而缩短中庭。

## 4. 鼻型

| 鼻型 | 识别 | 目标 | 手法 |
|---|---|---|---|
| 低塌鼻 low_bridge | 山根低平 | 立起山根 | 山根两侧（眼窝三角）起笔向下晕，**不要连到眉头**（会拉长中庭）；鼻梁中轴哑光提亮 |
| 短鼻 short | 鼻长短 | 视觉延长 | 鼻影上端接眉腰、下端到鼻尖；高光从山根拉到鼻中隔 |
| 长鼻 long | 中庭显长 | 缩短 | 鼻尖加阴影；鼻影只做山根两侧轻晕；高光只打在鼻梁中段 |
| 宽鼻/鼻翼宽 wide | 鼻翼外扩 | 收窄 | 鼻翼两侧阴影向内推；鼻梁高光**细而长**；鼻尖点高光 |
| 蒜头鼻 bulbous_tip | 鼻头圆钝肉厚 | 精修鼻头 | 鼻头两侧画"小括号"接鼻小柱成 V，括号不闭合、上缘不超过唇峰延长线；鼻头高光画**倒三角**而非圆点 |
| 鹰钩/驼峰 aquiline | 鼻背有凸起 | 顺滑 | 凸起两侧打阴影，凸起处轻扫余粉；高光断开避开凸点 |
| 歪鼻 crooked | 中轴偏斜 | 视觉校正 | 凸出侧用浅色遮瑕提亮，凹侧按对称弧度补阴影 |

> 通用原则：鼻影用**冷调灰棕**，不用暖棕/红棕（亚洲肤色用暖棕会显脏）。晕染顺序"先上下、再内外"，避免山根过细导致鼻头显大。

## 5. 唇型

| 唇型 | 识别 | 目标 | 手法 |
|---|---|---|---|
| 薄唇 thin | 上下唇都薄 | 增量 | 遮瑕盖原唇线 → 唇线笔外扩 0.5mm → 唇中央提亮 → 水光/镜面质地放大体积 |
| 厚唇 full | 唇体厚 | 收敛 | 边缘遮瑕弱化 → 深色叠在唇内侧 → 唇线内收 → 优先哑光 |
| 唇峰明显 sharp_bow | M 字清晰 | 保留或柔化 | 想柔和就用棉签把唇峰晕开；想精致就强调唇峰 |
| 唇峰弱 soft_bow | 线条平 | 造形 | 遮瑕盖原上唇线，用唇线笔画 V 形唇峰 |
| 嘴角下垂 downturned | 唇角低于唇中 | 提气 | 唇线笔把唇角微微上提；选接近原生唇色的色号，弱化存在感 |
| 大唇 large | 唇宽超过鼻翼垂线 | 缩小 | 先遮边缘再内收轮廓，颜色集中唇中 |
| 上薄下厚 uneven | 比例失衡 | 平衡 | 薄的那片用浅色 + 清晰唇线（显前突），厚的那片用深色 + 弱唇线（显后退） |

上下唇理想比约 1:1.4–1.5。人中偏短会显幼，偏长显成熟——唇峰位置上移可缩短人中视觉。

## 6. 眉

| 维度 | 枚举 | 影响 |
|---|---|---|
| 形状 | 平眉 / 微弯 / 挑眉 / 弯月 / 野生 | 决定上半脸气质与年龄感 |
| 粗细 | 细 / 中 / 粗 | 粗眉压气场，细眉显精明 |
| 浓度 | 稀疏 / 中 / 浓 | 稀疏适合"补空"式画法 |
| 眉峰 | 低 / 中 / 高 | 高眉峰提神，低眉峰柔和 |

**通用手法**：先定眉底线 → 定眉峰 → 连眉尾 → 顺毛流一根根补空隙 → 眉头最淡（"轻-重-轻-重"的轻重节奏）→ 螺旋刷晕开 → 染眉膏统一色调。
**颜色**：比发色浅一度；黑发也建议灰棕而非纯黑。**眉头虚、眉尾实、眉峰顺**。

## 7. 浓颜 / 淡颜：决定"能不能压住妆"

| 指标 | 计算 | 淡颜 | 浓颜 |
|---|---|---|---|
| 五官占比 | 眼裂面积 + 唇面积 / 脸面积 | 小 | 大 |
| 立体度 | 山根高度 + 眼窝深度 + 颧骨折叠 | 低 | 高 |
| 对比度 | 发色/瞳色 与 肤色 明度差 | 低 | 高 |
| 面部留白 | 五官外缘到脸缘的平均距离 | 多 | 少 |

- **淡颜**：妆越浓越显脏、显凶。主线是"提气色 + 精修局部"，全脸主色 ≤2，强度上限 0.45。
- **浓颜**：淡妆会"压不住"，可承载高对比（红唇、深眼线、强修容），强度上限 0.85。
- **反例提醒**：脸型圆钝 + 五官大 = 仍不适合浓妆（会显凶），应按"方圆脸"降强度。

## 8. 骨相 / 皮相

- **骨相**：轮廓折叠度、颧骨/下颌/眉骨立体度。骨相平整流畅 → 素颜耐看，妆容重点在"提亮 + 保留"。
- **皮相**：肤质、软组织、气血感。皮相差（暗沉、浮肿、泪沟）→ 妆容重点在"底妆干净度 + 哑光提亮凹陷"。
- 输出 `bone_vs_flesh` 连续值：>0.6 偏骨相（走立体/清冷路线），<0.4 偏皮相（走柔光/氛围路线）。

## 9. 皮肤（底妆决策的输入）

| 维度 | 枚举 | 影响 |
|---|---|---|
| 肤质 | 干 / 油 / 混干 / 混油 / 中性 / 敏感 | 决定妆前、粉底质地、定妆方式 |
| 深度 | 1–10（对应 ITA°） | 粉底色阶 |
| 冷暖 | cool / warm / neutral / olive | 粉底 undertone、全套配色 |
| 瑕疵 | 痘印 / 泛红 / 黑眼圈 / 泪沟 / 毛孔 / 法令纹 | 遮瑕与提亮的优先级 |
| 纹理 | 平整 / 粗糙 / 干纹 | 是否用"抛光"手法、是否避开珠光 |

**色彩校正逻辑**（互补色）：泛红用绿、黑眼圈偏紫用橘/蜜桃、暗黄用紫/蓝、暗沉用蜜桃。校正层在粉底之前，且必须薄。
