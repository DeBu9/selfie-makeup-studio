# 自拍妆效工作室 · selfie-makeup-studio

> 给一张自拍，出 **3 套适配妆容的效果图**，再给 **3 张能照着化出来的方案卡**。

不是滤镜，也不是"把某个博主的妆搬到脸上"。它先读你的脸——脸型、五官、肤色季型、浓淡颜——再按规则算出什么妆适合你、强度该给多少，最后才让图像模型动手。

所以换一张脸，出来的妆会不一样；换一个模型，出来的判断还是同一个。

---

## 它解决的是什么问题

直接问 AI"给我化个妆"，你通常会得到两类回答：

- **泛泛的建议**：「日常可以试试清透底妆，搭配豆沙色唇膏」——正确，但没法执行；
- **套模板的妆**：把热门妆容原样搬到脸上，不管你是方圆脸还是长脸。

这个 skill 把中间那段"判断"做成了确定性规则：

```
自拍 → 面部分析(JSON) → 规则引擎(确定性) → 妆容参数(0–1 强度) → 提示词 → 图
```

审美判断不交给模型，模型只负责画。所以：

- 你是淡颜，它不会给你 0.8 强度的浓妆（会被强制夹到 0.45）；
- 你中庭偏长，腮红一定横打跨鼻梁，不会竖着扫；
- 你暖皮，冷粉系（mauve / berry）会被直接剔掉。

## 你会拿到什么

一次跑完，产出这些文件：

| 文件 | 内容 |
|---|---|
| `index.json` | 三套方案摘要，先看这个 |
| `spec_01_*.json` | 完整妆容参数（每个部位 + 0–1 强度） |
| `prompt_01_*.txt` | 图像编辑提示词，可直接喂给图像工具 |
| `card_01_*.md` | 方案卡文本版 |
| `card_01_*.html` | **方案卡排版版**：自带原图/妆后对比、14 步分解、手法动效 |

方案卡里每一步都有六个要素：**工具 / 用量 / 位置 / 手法 / 停手标准 / 常见错**。

手法示意不是静态箭头，是按你这套妆的参数实时渲染的 SVG 动画——浅色宽带是范围，深色线是笔迹，小刷头沿着路径走、自动转向。仰头画眼线还是平视画，图里不一样。

三套的定位是固定的：**主推（最稳）/ 换个气质 / 妆感更明显一点**。挑一套就够，不用全部看完。

## 安装

这个 skill 是纯文件，没有服务、没有模型权重、不需要 GPU。只要宿主支持 skills 目录即可（豆包、Claude Code、WorkBuddy 等）。

### 方式一：让 agent 自己装（推荐）

在对话里直接发：

```
帮我安装这个技能：https://github.com/DeBu9/selfie-makeup-studio
```

它能读 GitHub 的 agent 会自己下载、放到位、跑自检。装完会告诉你装在哪、缺什么依赖。

### 方式二：手动放目录

```bash
git clone https://github.com/DeBu9/selfie-makeup-studio.git
```

把整个目录放进宿主的 skills 路径，例如：

| 宿主 | 路径 |
|---|---|
| Claude Code | `~/.claude/skills/selfie-makeup-studio/` |
| WorkBuddy | `~/.workbuddy/skills/selfie-makeup-studio/` |
| 豆包 | 在"插件·技能·伙伴 → 技能 → 添加 → 上传技能"里选这个文件夹 |

目录里必须有 `SKILL.md`，宿主要靠它识别技能名和触发条件。

如果你手上是压缩包，解压后放进同样的位置即可——目录结构就是上面这个样子。

装完验证一下：

```bash
python scripts/plan_makeup.py --selftest
```

会在 `scripts/_selftest/` 生成三套样例，说明规则引擎和卡片模板都正常。

## 用法

对 agent 说一句就行，比如：

```
帮我化个妆看看，明天面试
```

它会做三件事：

1. **问三个问题**：什么场合、想要什么感觉、有什么忌讳（不要假睫毛/不要深色唇之类）。说不出感觉就说"随便"，它按你的脸推荐。
2. **出三套图**：都从原图出发，不会在上一张的基础上继续改（那样会越改越不像）。
3. **给方案卡**：你挑一套，它把对应卡片打开。

出图前它会先告诉你成本（每张约 5–10 积分），得到同意才生成——不会偷偷扣。

想手动跑命令也行：

```bash
python scripts/plan_makeup.py \
  --analysis makeup_out/analysis.json \
  --brief '{"occasion":"通勤","style":"auto","avoid":["假睫毛"]}' \
  --out makeup_out/plan
```

出图后还要跑两条，把图嵌进卡片：

```bash
python scripts/attach_result.py --plan makeup_out/plan \
  --original <原图路径> --map korean_glass=makeup_out/images/korean_glass.png

python scripts/attach_motion.py --plan makeup_out/plan
```

要发到手机或微信，再导一份长图 / PDF：

```bash
python scripts/export_share.py --card makeup_out/plan/card_02_korean_glass.html \
  --out makeup_out/share --name "韩系水光_方案卡"
```

## 规则引擎在算什么

| 环节 | 规则 |
|---|---|
| 强度 | `配方强度 × 场合系数`，夹在 `min(浓淡颜上限, 脸型上限)` 之间。淡颜 0.45 / 中等 0.65 / 浓颜 0.85 |
| 场合 | 上课 0.80 · 通勤 0.85 · 日常 1.00 · 约会 1.05 · 拍照 1.15 · 派对晚宴 1.30 |
| 中庭偏长 | 强制腮红横打跨鼻梁、鼻影不连眉头、卧蚕下移 |
| 脸型 | 圆/方圆/方 → 弧线收下颌角；长脸 → 横腮红、降修容；菱形 → 提亮太阳穴 |
| 眼型 | 内双/单眼皮 → 只填内眼线或眼尾 1/3 起笔；肿眼泡 → 全哑光、范围压到褶皱 |
| 冷暖 | 暖皮剔冷粉系、冷皮剔暖橘系，全被剔掉时按季型兜底 |
| 三套怎么选 | ①分数最高 ②换一个气质组 ③强度上一档（分数不能掉太多） |

要加新风格，只改 `data/style_recipes.json` 一条配方，其他文件不用动。

## 边界

这个 skill 刻意不做一些事，因为它们会毁掉"还是本人"这个前提：

- **不改骨相**：不瘦脸、不开眼角、不垫鼻梁、唇厚变化 ≤ ±10%
- **不美白**：只做均匀 + 提亮半度，肤色深度变化 ≤ 1 阶
- **不接未成年人**，不评价"该医美"
- 只处理本人或已获授权的照片，输出标注 AI 生成
- 提示词里禁用 `beautiful` `flawless` `stunning` 这类词——它们会把脸推向模型的"平均美"，身份立刻漂移

## 常见问题

**出的图不像我？**
强度乘 0.7，从**原图**重跑（不要在上一版输出上继续改），`input_fidelity` 拉到最高，确认提示词里没有美颜词。

**妆几乎没上？**
强度提到 0.35 以上。强度太低时模型会理解成"保持原样"。

**手法图不会动？**
先确认你看的是哪个文件：长图 `.png` / `.pdf` 是静图，动不了是格式决定的；`card_*.html` 用浏览器打开会动。另外系统开了"减弱动态效果"（`prefers-reduced-motion`）也会关掉动画。

**微信里打不开卡片？**
微信不能开本地 HTML。用 `export_share.py` 导长图和 PDF，微信原生支持。

**没有图生图能力怎么办？**
仍可用：拿提示词去支持图生图的工具里生成，或者只交付方案卡。不要让文生图硬凑——出来的不是本人，那就不叫试妆。
